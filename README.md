# EnhancedAlarm
EnancedAlarm is an app for mobile devices. It works like a regular alarm with an additional functionality of making the user do tasks to turn off the alarm. The tasks center around using device's camera to make the user either do something with their body or show a particular item. Additionally tasks possible to do with only the device like math problems.

# Project goals
## Necessary features
 - setting and playing the alarm to a chosen time
 - turning off the alarm by doing the task
## Necessary tasks
 - doing pushups

## Optional features
 - setting alarms to a designated day of a week
 - option to customize wanted tasks
## Optional tasks
 - doing jumping jacks
 - showing item to the camera (cutlery, regular household furniture, sink, toilet, etc)
 - math problems
 - puzzles
